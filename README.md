## 🏫 Sobre o Projeto
Este repositório contém o desenvolvimento de uma aplicação analítica para investigar padrões de evasão escolar no ensino médio brasileiro entre os anos de 2015 e 2024. O objetivo é identificar regiões mais afetadas, analisar a evolução temporal, comparar redes de ensino (pública vs. privada) e investigar fatores socioeconômicos (como renda) associados ao abandono escolar.

---

## 📂 Estrutura do Repositório
* `app.py`: Código-fonte do dashboard interativo desenvolvido em Streamlit.
* `index.html`: Página web de apresentação do projeto (publicada via GitHub Pages).
* `requirements.txt`: Lista de dependências e bibliotecas Python necessárias (`pandas`, `streamlit`, `plotly`, `matplotlib`, `seaborn`).
* `dados/`: Pasta contendo a base de dados em formato CSV.
* `notebooks/`: Contém o Jupyter Notebook (`analise_evasao_escolar.ipynb`) com a análise exploratória e tratamento dos dados.
* `database/` e `imagens/`: Pastas de suporte para estruturação profissional do projeto.
